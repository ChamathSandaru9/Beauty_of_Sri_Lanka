# Beauty of Sri Lanka

A modern, responsive tourism website built with React to showcase the natural beauty, culture, wildlife, experiences, and traditional food of Sri Lanka.

## 🌴 About the Project

**Beauty of Sri Lanka** is a one-page tourism website designed to help visitors explore the beauty and diversity of Sri Lanka.

The website features popular destinations, exciting travel experiences, unique wildlife, and traditional Sri Lankan cuisine through a clean and responsive user interface.

## ✨ Features

* Responsive navigation bar
* Hero image slider
* Destinations section
* Experiences section
* Wildlife section
* Sri Lankan Food section
* Responsive card layouts
* Smooth scrolling navigation
* Mobile, tablet, and desktop support
* Footer with social media links

## 🛠️ Technologies Used

* React
* JavaScript
* HTML5
* CSS3
* Vite
* React Icons

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project folder

```bash
cd Beauty_of_Sri_Lanka
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The website will normally be available at:

```text
http://localhost:5173
```

## 📱 Responsive Design

The website is designed to work across different screen sizes:

* Desktop
* Laptop
* Tablet
* Mobile

The destination, experience, wildlife, and food cards automatically adjust their layout according to the screen size.
